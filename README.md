# Math'as Hub — V3 affinée, version regroupée

Cette version repart de la V3 affinée.

Modifications :
- Calcul / Géométrie / Grandeurs sont regroupés à l'affichage ;
- les niveaux Objectif / Dépassement / Révision / Outils restent séparés ;
- les données de domaine restent présentes dans Supabase pour être réactivées plus tard ;
- une application n'apparaît qu'une seule fois dans son niveau ;
- sous-titre : "Le hub de math de Monsieur Tatas" ;
- Objectif et Outils sont ouverts par défaut ;
- Dépassement et Révision sont fermés par défaut ;
- les titres de niveaux utilisent une police plus classique et lisible ;
- Math'as et Sélection du jour conservent leur style actuel.

Installation :
1. Décompresser le ZIP.
2. Dans GitHub > dépôt Mathas > Add file > Upload files.
3. Remplacer index.html, styles.css, app.js, config.js et README.md.
4. Commit changes.
5. Attendre le redéploiement GitHub Pages.
6. Ctrl + F5 sur le hub.
