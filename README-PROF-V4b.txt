MATH'AS — PAGE PROF V4b : AJOUT D'IMAGES GENERALES

Nouveau bouton :
+ Ajouter une image

Il se trouve à côté de :
+ Ajouter une appli

Il permet :
- glisser-déposer une image ;
- choisir un dossier :
  * logos
  * backgrounds
  * interface
  * illustrations
  * autres
- envoyer l'image dans le bucket Supabase `mathas-images` ;
- obtenir immédiatement son URL publique ;
- copier cette URL ;
- ouvrir l'image dans un nouvel onglet.

Les miniatures des applis continuent à utiliser automatiquement :
miniatures/

Aucun changement SQL ou Supabase supplémentaire n'est nécessaire.

Dans GitHub, remplacer :
- teacher.html
- teacher.css
- teacher.js
