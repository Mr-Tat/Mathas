FONCTIONNEMENT
--------------
Toutes les applis :

- pas de Objectif / Dépassement / Révision / Outils ;
- une seule grille simple ;
- scores Dernier / Meilleur affichés ;
- dans la page prof : seulement Visible / non visible.

Partage :
- même grille simple ;
- PAS de scores ;
- dans la page prof : seulement Visible / non visible ;
- conçue pour donner son URL aux collègues.

NOUVELLES APPLIS
----------------
Quand tu crées désormais une nouvelle appli dans la page prof :
- elle est créée dans Observation, Phase 1, Phase 2, Toutes les applis et Partage ;
- elle est visible automatiquement dans Toutes les applis ;
- elle reste invisible dans les autres pages jusqu'à ce que tu l'actives.
